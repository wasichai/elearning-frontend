# Pantalla · Ficha de curso (móvil)

La ficha del catálogo en móvil: una columna, la edición abierta resumida en un aviso y «Matricularme» fijo al pie.

## Reglas
- La barra inferior fija lleva precio (o «Gratis»), fecha de inicio y la única acción primaria; no se oculta al desplazar porque es la razón de la página.
- Los hechos se apilan en una columna con iconos de 44px.
- Con más de una edición abierta, el aviso se convierte en un select «Edición» encima de la barra inferior.
- El temario muestra solo la unidad 1 abierta para no alargar la página.
