# Pantalla · Lección de lectura (móvil, modo lectura)

La misma lección en móvil con el tema `lectura` activo: barra mínima con progreso de lectura, texto a 18/30 y acción fija al pie.

## Reglas
- Margen lateral `space-4`; texto `read-body` móvil (18/30).
- La barra fina bajo el título muestra el avance **dentro** de la lectura; el avance del curso está en «Temario».
- «Temario» abre una hoja inferior con el `Syllabus`.
- La acción al pie queda fija y ocupa el ancho; se oculta mientras se desplaza hacia abajo y reaparece al subir o al llegar al final.
