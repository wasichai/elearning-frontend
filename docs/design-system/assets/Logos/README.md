# Logos

Marca propuesta por este sistema (no había logotipo en las fuentes): un cordón principal con tres cuerdas y cuatro nudos en terracota, maíz y musgo.

- `wasichai-quipu-mark.svg`: sobre fondos claros (`bg`, `surface`). Tinta `#1e2327` (= `ink` claro), cuerdas `#857a66` (= `line-strong`).
- `wasichai-quipu-mark-dark.svg`: sobre fondos oscuros; mismos roles con los valores del tema oscuro.
- Acompáñala del nombre «wasichai» en Figtree 700, a la derecha, con un hueco de `space-2`/`space-3`. Tamaño mínimo 20px; área de respeto igual a un nudo.
- No la recolorees fuera de los tokens ni la uses como patrón de fondo.
