# EmptyState

Estado vacío ilustrado con cordones de quipu: dice qué falta, por qué y qué hacer a continuación.

## Ilustraciones
Una sola familia: cordones (`line-strong`) con nudos. Los nudos cuentan la historia:
- **Vacío**: nudos sin anudar (huecos).
- **Búsqueda sin resultados**: un nudo terracota entre huecos.
- **Error**: un cordón roto (trazo discontinuo) con un nudo `danger`.
- **Todo hecho**: nudos musgo y uno de maíz.

Nada de personajes, mascotas ni escenas: las formas son el sello del sistema.

## Qué aporta quien lo usa
Título (lo que pasa, en una frase), descripción (por qué o qué viene), una acción primaria o ninguna. En errores, la descripción tranquiliza sobre lo que no se perdió.

## Reglas
Centrado, `max-width` 440px; dentro de una tarjeta o del área de contenido, nunca a pantalla completa vacía.
