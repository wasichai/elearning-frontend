# Pantalla · Finalización del curso

Celebración contenida al completar: sello de maíz que se anuda una sola vez, cifras reales del recorrido y una única acción hacia el certificado.

## Reglas
- La única animación de celebración del producto (`duration-celebrate`, `ease-knot`); con movimiento reducido el sello aparece sin animar.
- Sin confeti, sin sonidos, sin puntos. Las cifras («60 horas», «17 sobre 20») son el premio.
- `wq-btn--celebrate` solo aquí y en la tarjeta del curso completado.
- Si falta un requisito (asistencia mínima, entrega pendiente de corrección), la pantalla no celebra: muestra lo que falta con su estado y fecha.
