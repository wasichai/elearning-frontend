# Pantalla · Mis cursos (móvil)

Versión móvil primero de «Mis cursos»: barra superior con menú plegable, retomar en una tarjeta compacta y tarjetas a una columna.

## Reglas
- Margen lateral `space-4`; acción de retomar a ancho completo.
- El anillo baja a 48px (`wq-ring--sm`) y la cifra se conserva.
- El quipu de cada tarjeta se mantiene: es la forma más compacta de ver el curso entero.
- La navegación vive en el cajón (`SideNav`), nunca en una barra inferior con más de 4 destinos.
