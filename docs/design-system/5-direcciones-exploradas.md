# Direcciones exploradas

Antes de desarrollar el sistema se compararon tres personalidades. Se eligió **Quipu**.

## Quipu — «cada nudo cuenta» (elegida)
- **Concepto**: el quipu andino registraba cantidades con nudos en cuerdas. Aquí cada lección, evaluación y sesión es un nudo; el curso es un cordón. El progreso es contable y honesto, con una raíz andina que está en la idea y no en ornamentos.
- **Paleta**: papel `#f7f3ea`, tinta `#1e2327`, terracota `#a5472a`, maíz `#d99a1e`, musgo `#2e6a44`.
- **Tipografías**: Literata (lectura) + Figtree (interfaz).
- **Aula**: tarjeta de curso con quipu «●─●─◆─●─◉─○─◇─○  5 de 8», plazo en aviso cálido, «Continuar lección 5».
- **Por qué**: es la única que aporta una forma propia (el nudo) que sirve a la vez como marca, como indicador de progreso y como ilustración de estados vacíos.

## Altiplano — «aire para pensar»
- **Concepto**: luz de altura, mucho espacio, horizontes en bandas.
- **Paleta**: piedra `#eef0ee`, pizarra `#22292b`, lago `#1f6f78`, ocre `#c8892b`, ichu `#8a9a5b`.
- **Tipografías**: Source Serif 4 + Public Sans.
- **Aula**: barra de progreso horizontal larga, próxima sesión destacada.
- **Descartada**: muy calmada pero genérica; sin un elemento que la haga reconocible.

## Cochinilla — «tinta y margen»
- **Concepto**: cuaderno editorial, notas al margen, un único carmín de cochinilla.
- **Paleta**: papel `#fbfaf7`, tinta `#17191a`, carmín `#a3183a`, grafito `#5b6166`.
- **Tipografías**: Newsreader + IBM Plex Sans.
- **Aula**: lista tipográfica, porcentaje a la derecha, «Seguir leyendo →».
- **Descartada**: excelente para leer, pero el carmín como marca choca con el rojo de error y el tono académico resulta frío para quedarse.

Del descarte quedan dos ideas en Quipu: el carmín de Cochinilla vive como `danger`, y los márgenes amplios de Altiplano como la medida de lectura.
