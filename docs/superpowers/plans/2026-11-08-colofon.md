# Colofón: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objetivo.** Sustituir el sistema visual Quipu por **Colofón** (dirección A elegida el 8 de noviembre de 2026) en `elearning-frontend` y añadir la agenda del estudiante que necesita la pantalla «Horario» en `elearning-backend`.

**Arquitectura.**

- Colofón es un tema `[data-theme]` que redefine los tokens de `@wasichai/ui`, más estilos sobre `data-slot` y utilidades `@theme` de Tailwind 4. No se añade ninguna librería de componentes.
- Las pantallas se recomponen con los componentes de `@wasichai/ui` y `@wasichai/core`, y con primitivas propias en `src/shared/`.
- El backend gana un endpoint de solo lectura, `GET /api/lms/classroom/sessions`, sobre el `SessionService` que ya existe.

**Stack:** React 19, Vite 8, Tailwind 4.3, `@wasichai/*` 1.8.1, Vitest, Playwright. Backend: Kotlin 2.4, Spring WebFlux, `DatabaseClient`.

**Spec (fuente de verdad).**

- Canvas A: https://claude.ai/artifact/3FfeqzTPiBKQzEcKR7MqKc
- Sus fuentes `.dc.html`, que la tarea 1 copia a `elearning-frontend/docs/design-system/colofon/`. `Foundations.dc.html` fija tokens, escala y rejilla. Cada pantalla tiene su artboard: `Dashboard`, `Catalog`, `CourseDetail`, `Classroom`, `Schedule`, `Mobile` y `Responsive`.
- Auditoría y decisión: https://claude.ai/artifact/2vSwNNERREDaTSCPQMbU1C
- Épica: wasichai/elearning-frontend#217. Cada tarea es un issue y un PR; se fusiona con squash cuando la CI está en verde.

**Orden de ejecución:** 1 → 2 → 3 → R1 → 4 → R2 → 5 → 6 → 7 → 8 → 9 → 10.

- **Tipografía:**
  - Newsreader, variable (`opsz` 6–72, `wght` 300–700, normal e itálica), para títulos y lectura, con `font-optical-sizing: auto`.
  - Source Sans 3, variable (`wght` 300–800, normal e itálica), para la interfaz, con `font-variant-numeric: tabular-nums lining-nums`.
  - Las dos se autoalojan en woff2, con su licencia OFL.
- **Escala (tamaño / interlineado / peso):**
  - Títulos en Newsreader: display 56/60/330, h1 44/50/380, h2 32/38/440, h3 25/31/520, h4 20/27/600.
  - Interfaz en Source Sans 3: h5 17/24/650; meta 15/20/600 en versalitas (`all-small-caps`, +0,07em); body 16/24/400; secondary 14/20/400; label 15/20/600.
  - Lectura en Newsreader: reading 20/33/400.
- **Medidas:**
  - Espaciado `--space-1`…`--space-9` = 4, 8, 12, 16, 24, 32, 48, 72, 112.
  - Anchos: `--measure` 66ch, `--index-col` 280px, `--margin-col` 264px, `--content-max` 1200px.
  - Rejilla: 4/8/12/12 columnas a 390/768/1280/1440; medianil 16/24/24/24; margen 16/32/48/72.
- **Composición:**
  - Sombras solo en lo que flota: `--shadow-overlay` 0 12px 32px rgb(23 32 43 / 16%).
  - Filetes en lugar de cajas: `--rule` 1px `--border`; `--rule-strong` 1px `--ink` para abrir cada sección «§».
- **Accesibilidad:** WCAG 2.2 AA. Objetivos de 44 px. Foco con anillo de 2 px `--focus` y separación de 2 px. Ningún estado solo por color.
- **Qué desaparece:** Quipu por completo, es decir, `quipu*.css`, las fuentes Figtree y Literata, `QuipuMark`, `CordBanner`, los nudos de `Quipu.tsx` y el color maíz.
- **Datos:** ni datos ni funciones inventados. Lo que la API no da (horas por tipo cuando faltan, plazas…) se oculta; no se pone un marcador en su lugar.

## Foco de revisión (lo que los tests no ejercitan y más puede doler)

1. **Un curso con muchas lecciones** (40 o más, unidades sin lecciones): el progreso segmentado sigue en una fila y legible, y el texto cuenta bien. Test en la tarea 4.
2. **Títulos largos** (más de 90 caracteres) en la cabecera corrida, el catálogo y el horario: se cortan con elipsis y el título completo va en `title`, sin desbordar a 390 px. Test en las tareas 5 y 8.
3. **Tema oscuro y sepia en cada pantalla nueva:** ningún color fijo fuera de tokens. Lo cubre el test de tokens (tarea 2) y una búsqueda de `#` en los `.tsx` (tarea 10).
4. **Horario con zonas horarias distintas** (edición en America/Lima y navegador en otra zona): las horas se muestran en la zona de la edición, como hoy. Test en la tarea 3 (backend) y en la tarea 9.
5. **Matrícula retirada o finalizada:**
   - La retirada no aparece en el horario.
   - La finalizada aparece en el panel como completada, con su certificado.
   - Test en las tareas 3 y 6.

sealed interface Block  // type: heading | paragraph | list | table | code | quote | admonition | figure | rule
data class Heading(val level: Int /*2..4*/, val id: String?, val content: List<Inline>) : Block
data class Paragraph(val content: List<Inline>) : Block
data class ListBlock(val ordered: Boolean, val items: List<List<Block>>) : Block
data class Table(val caption: List<Inline>?, val head: List<List<Cell>>, val body: List<List<Cell>>) : Block   // Cell(content: List<Block>, colspan: Int = 1, rowspan: Int = 1, header: Boolean)

data class Quote(val content: List<Block>, val attribution: List<Inline>?) : Block
data class Admonition(val kind: String /*note|tip|important|warning|caution*/, val content: List<Block>) : Block

- **Admoniciones.** Las de Asciidoctor (`div.admonitionblock.<kind>`) van a `Admonition`, y los bloques de código (`pre > code[data-lang]`) van a `Code`.
